# Reference v12：完整功能單畫面控制台

## 2026-08-02 入口去重與週期補強

首頁上方四個主要模式已直接提供「生日分析、數字頻譜、三數取卦、康節易學」，下方功能總覽不再重複這四格，改列十八項支援工具。桌面／平板為 6 欄 × 3 列完整矩陣；手機維持 4 欄，最後兩格置中。四個主要模式加十八項工具，仍是 22 個唯一入口，沒有刪除功能。

生日結果另補個人月與個人日，兩者標示為 `personal-calendar-cycles-common-v1` 現代流傳公式，不冒充古籍或科學定論。

## 目的

首頁共提供 22 個唯一功能：四個主要模式放在分析器切換列，另有十八項支援工具放在功能總覽；原本藏在「康節易學」專頁內的六大方法仍可直接進入。

## 版面規則

- 桌機：四個主要模式＋6 欄 3 列十八項工具。短高螢幕取消舊版最低高度，`1280×640` 仍需完整顯示。
- 平板：四個主要模式＋6 欄 3 列十八項工具；主視覺、分析器、摘要與功能牆連續排列。
- 手機：四個主要模式＋4 欄五列十八項工具；最後 2 格置中，消除重複入口並縮短首屏。
- 完整分析內容仍可向下捲動；「單畫面」指首頁所有功能入口均在首屏可見，不以縮小完整報告文字換取假性塞入。

| 字占姓名 | `public/visuals/ai-dashboard/reference-v12/kangjie-text-v12.webp` | 無字卷軸、毛筆、金墨筆畫路徑與計數環 |
