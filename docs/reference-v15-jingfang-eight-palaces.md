# Reference v15：京房八宮六十四卦完整表

## 功能邊界

此模組是三數取卦完成後的「歸宮與世次分類」，不參與起卦。

- 三數取卦仍採 `modern-three-number-xiantian-v1` 的既有公式。
- 京房模組只以本卦、互卦、變卦的通行卦序查出宮別、五行與世次。
- 不新增吉凶、預測或決策建議。
- 全部規則集中在 `jingfang-palaces.js`，靜態 GitHub Pages 與 React 畫面共用同一資料源。

## 八宮與世次

欄位固定為：

`本宮（六世）、一世、二世、三世、四世、五世、遊魂、歸魂`

六爻由初爻到上爻儲存。相對於本宮純卦，各欄翻轉的爻索引如下：

| 世次 | 翻轉爻位（0 起算） |
|---|---|
| 本宮 | 無 |
| 一世 | 0 |
| 二世 | 0、1 |
| 三世 | 0、1、2 |
| 四世 | 0、1、2、3 |
| 五世 | 0、1、2、3、4 |
| 遊魂 | 0、1、2、4 |
| 歸魂 | 4 |

畫面行序依使用者參考表採：

`乾、坎、艮、震、巽、離、坤、兌`

傳世資料與校勘表常見編次為：

`乾、震、坎、艮、坤、巽、離、兌`

兩者只差畫面排序，八宮成員及世次完全相同。介面已在來源說明中明確揭露，不把參考圖行序冒充原書唯一編次。

## 驗證條件

- 八宮各 8 卦，合計 64 格。
- 第 1 至第 64 卦各出現一次，無遺漏及無重複。
- 卦名亦 64 個唯一。
- 本卦唯一使用 `aria-current="true"`。
- 本卦、互卦、變卦若落在同一格，必須同時保留各自的文字標記。
- 桌機顯示完整 9 欄表格。
- 手機以同一語意表格重排為每宮 2 欄 4 列，所有 64 卦仍在同一頁，頁面不得產生水平溢位。
