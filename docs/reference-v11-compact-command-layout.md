# Reference v11 緊湊指令台

## 目的

本版依桌機與手機參考稿重組資訊層級，重點是「同一畫面直接操作」，不是單純更換顏色。

- 桌機：四種分析模式、即時分析總覽與 16 個功能入口集中在首屏。
- 平板：四項結果採單列，16 個功能入口採 8 欄 2 列。
- 手機：省略重複主視覺，保留四種分析模式、輸入區、四項結果與 16 個功能入口；入口採 4 欄 4 列。
- AI 圖像只作辨識底圖；名稱、狀態與演算結果均為真實文字節點，不把文字烘焙進圖片。

## 「核心數」語意修正

舊版右側「核心數字」在不同模式代表不同內容，也和結果預覽重複。本版改為「本次主要結果」，並依模式顯示具體標籤：

- 生日命碼：生命路徑數。
- 數字頻譜：號碼歸一數。
- 三數取卦：本卦卦象。

演算結果內仍保留數字頻譜的歸一計算，但不再把它當成所有功能共用的「核心數」。

## 16 個直接入口

1. 生日分析
2. 生命路徑
3. 數字頻譜
4. 九宮配置
5. 個人流年
6. 適合色彩
7. 三數取卦
8. 姓名筆畫
9. 康節易學
10. 身分證命格
11. 手機磁場
12. 車牌門牌
13. 自訂序列
14. 本機紀錄
15. 規則設定
16. 規則來源

手機磁場、車牌門牌與自訂序列會直接切到工作台內對應輸入類型；姓名筆畫會開啟受密碼保護的康節專頁並預選字占／姓名加數模式。

## 驗收契約

- 16 個模組名稱唯一且中央可點。
- 1672×941、1440×900、390×844、320×720 的首屏完整顯示全部入口。
- 768px 以上入口採 8 欄；767px 以下採 4 欄。
- 沒有水平溢位、標籤裁切或裝飾層攔截點擊。
- 三數取卦與康節易學仍使用密碼 `0000`。
