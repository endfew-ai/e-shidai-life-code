# 梅花易數演算方法

版本：`kangjie-calculation-trace-v2`

## 共用規則

- 六爻由初爻至上爻儲存。
- 下卦為第 1 至 3 爻，上卦為第 4 至 6 爻。
- 卦數用 `mod1(total, 8)`，整除時為 8。
- 動爻用 `mod1(total, 6)`，整除時為 6。
- 互卦下卦取本卦第 2、3、4 爻。
- 互卦上卦取本卦第 3、4、5 爻。
- 動爻在第 1 至 3 爻時，下卦為用、上卦為體。
- 動爻在第 4 至 6 爻時，上卦為用、下卦為體。
- v2 對每次除 8、除 6 保存被除數、除數、商、餘數、最後取值及整除規則，避免只留一行不可重播的摘要。

## 古籍主法、今法與現代三數的界線

| 類型 | 程式入口／profile | 定義與界線 |
|---|---|---|
| 古籍主法 | `classic-primary-v1` | 依本次核對的《梅花易數》傳本文字實作年月日時、物數、聲音、字占、丈尺尺寸與後天端法；異讀另外保存，不宣稱傳本無爭議。 |
| 今法 | `modern-current-v1` | 沿用可核傳本的卦數核心，但允許版本化的現代曆法、Unicode／教育部筆畫 provider；「今本」不等於古籍原文，也不會把現代資料倒稱為古法。 |
| 現代三數 | `calculateModernThreeNumberMethod`，預設 `modern-current-v1` | 三個固定數字依序取上卦、下卦、動爻。本次核對未在《梅花易數》古籍主法找到此固定三輸入公式，因此結果永遠保留「現代三數法」警告。 |

現代三數不自動代入生日、身分證或其他個資，也不可因改選 profile 就重新命名成古籍主法。

## 現代三數取卦

```text
上卦數 = 第一數
下卦數 = 第二數
動爻數 = 第三數
```

三個輸入都必須是大於 0 的完整整數；上、下卦各除以 8，動爻除以 6，整除時分別取 8、6。這是本工具的版本化現代入口，不是年月日時、物數或聲音法的別名。

## 年月日時

```text
上卦數 = 年支數 + 農曆月 + 農曆日
下卦數 = 年支數 + 農曆月 + 農曆日 + 時支數
動爻數 = 年支數 + 農曆月 + 農曆日 + 時支數
```

十二地支依序為子 1 至亥 12。

## 物數

```text
上卦數 = 可數物件數
下卦數 = 時支數
動爻數 = 可數物件數 + 時支數
```

## 聲音

### 單一聲數

```text
上卦數 = 聲數
下卦數 = 聲數 + 時支數
動爻數 = 聲數 + 時支數
```

這是對傳本文字「數得幾數，起作上卦，加時數配作下卦」的明示實作解讀，結果會保留該假設。

### 分段聲數

```text
上卦數 = 第一段聲數
下卦數 = 第二段聲數
動爻數 = 第一段聲數 + 第二段聲數 + 時支數
```

## 字占

### 一字

楷書左部陽畫作上卦，右部陰畫作下卦，左右合計取動爻。Unicode 總筆畫無法自動拆成左右陰陽畫，因此必須人工確認。

### 二至三字

依每字總筆畫分組。偶數字數平分；奇數字數少一字在上、多一字在下。各組筆畫合計取上下卦，全部筆畫合計取動爻。

### 四至十字

古籍主法採人工確認的平、上、去、入，依序為 1、2、3、4。不可用現代國語四聲自動冒充。另提供明確標示的使用者筆畫分組模式。

### 十一至一百字

只計漢字。偶數平分；奇數少一字在上、多一字在下。上下字數合計取動爻。

## 丈尺與尺寸

丈尺占：

```text
上卦數 = 丈數
下卦數 = 尺數
動爻數 = 丈數 + 尺數
寸數不用
```

尺寸占：

```text
上卦數 = 尺數
下卦數 = 寸數
可核傳本主法動爻 = 尺數 + 寸數 + 時支數
未證流傳異法動爻 = 尺數 + 寸數
```

目前可核的《梅花易數》轉錄與影本均支持尺寸合數加時取爻；不加時只為相容需求保留，介面與結果不得把它冒充為已證古本。

## 後天端法

```text
上卦 = 使用者確認的物象卦
下卦 = 使用者確認的方位卦
動爻數 = 物象卦數 + 方位卦數 + 時支數
```

為人、自己、動物、靜物及方位入口共用此引擎，但保留不同 scenario。物象文字只回傳候選，不自動宣稱唯一對應。動物及靜物若未輸入觸發事件會顯示「不動不占、無故不占」警告。

## 五行多關係與月令旺衰

v2 不再只保存本卦體、用的一組關係，而是以同一體卦逐一計算：

1. 本卦用卦。
2. 互卦下互。
3. 互卦上互。
4. 變卦用方。

每一位置均回傳比和、體生用、用生體、體克用或用克體之一。`partyBalance` 另計互變四個觀察位置中與體五行、用五行相同的數量；體用比和時不把同一五行重複分作兩黨。

有農曆月輸入時，`seasonalStrength` 依傳本文字標示「旺、衰、平」：

| 月令 | 旺 | 衰 | 其他 |
|---|---|---|---|
| 正、二月（寅、卯月／春） | 震、巽木 | 艮、坤土 | 平 |
| 四、五月（巳、午月／夏） | 離火 | 乾、兌金 | 平 |
| 七、八月（申、酉月／秋） | 乾、兌金 | 震、巽木 | 平 |
| 十、十一月（亥、子月／冬） | 坎水 | 離火 | 平 |
| 三、六、九、十二月（辰、未、戌、丑／四季土月） | 艮、坤土 | 坎水 | 平 |

旺衰只作結構標記，並寫入 `calculationTrace`；系統不把旺、衰自動延伸成吉凶、事件預測或決策建議。

## 姓名或姓氏加數

```text
加數 = 所輸入姓名或姓氏的逐字筆畫合計
上卦數 = 年支 + 農曆月 + 農曆日 + 加數
下卦數 = 上卦數 + 時支
動爻數 = 下卦數
```

每個字的筆畫、來源、資料版本及人工覆寫狀態都寫入演算追蹤。本次核對卷一未找到足以支持此單一公式的原文，所以此入口標為流傳／使用者指定規約，不冒充古籍主法。
